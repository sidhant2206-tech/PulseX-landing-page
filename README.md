# PulseX - Responsive Product Landing Page

A fully responsive landing page for **PulseX**, a fictional smartwatch brand.
Built as the Week 02 Minor Project for the Unlox Web Development course.

## Sections
- Navigation bar with mobile hamburger menu
- Hero section with title, description, image and CTA buttons
- Features section (5 cards)
- Benefits section with unique selling points
- Testimonials section (3 reviews)
- Pricing section with 3 plans and a CTA banner
- Footer with contact info, social links and copyright

## Tech Stack
- HTML5
- CSS3 (gradients, transitions, hover effects, media queries)
- Tailwind CSS (via CDN)
- Flexbox and CSS Grid
- Vanilla JavaScript (mobile menu toggle)

## Responsive Design
Tested on mobile, tablet and desktop screens using Tailwind breakpoints (sm, md, lg).

## How to Run
1. Clone this repository or download the ZIP
2. Open index.html in any browser
(Internet is needed because Tailwind loads from a CDN.)
